PORTFOLIO DE PRESLEY EXAUCE NGOMBOLO

Fichiers
- index.html : contenu et organisation des sections
- style.css : couleurs, mise en page et adaptation aux petits écrans
- presley.jpeg : photo du portfolio

Pour ouvrir le portfolio
Ouvre index.html dans un navigateur. Le site fonctionne sans installation. Les liens e-mail et WhatsApp nécessitent une connexion pour ouvrir le service correspondant.

Notions utilisées
- HTML : structure du document, titres, paragraphes, listes, liens, images et sections.
- CSS : sélecteurs, classes, couleurs, espacements, bordures et modèle de boîte.
- Flexbox : aligne les éléments du menu, des projets et des contacts.
- CSS Grid : organise la présentation d'accueil et les cartes de compétences.
- Variables CSS : les valeurs définies dans :root permettent de réutiliser la même palette.
- Media query : @media (max-width: 768px) adapte la mise en page aux petits écrans.
- Les liens du menu associent href="#profil" à id="profil" pour atteindre la section correspondante.

Pour présenter le code
Explique d'abord comment index.html organise les sections. Puis montre comment style.css cible les classes avec un point, par exemple .portrait. Pour la photo, border-radius crée les coins arrondis. Pour le menu, href="#profil" pointe vers la section qui porte id="profil". Pour le responsive, la règle @media change la grille de deux colonnes à une colonne sur un écran étroit.
